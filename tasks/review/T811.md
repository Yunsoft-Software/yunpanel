## Yapılanlar
- `e2e/ozellik/dev-06.spec.js` dosyasındaki `afterAll` hook'unda bulunan genel yıkıcı komut (`rm -f /etc/cron.d/yunpanel-*`) tamamen kaldırıldı. Bu komut sunucudaki tüm sitelerin yönetilen cron dosyalarını silme riski taşıyordu.

  1. Arayüzden Laravel Schedule Worker eklendi, panel API'sinden spesifik `taskId` alındı ve SSH ile `/etc/cron.d/yunpanel-${mainTaskId}` dosyasının oluştuğu doğrulandı.
  2. Panel API üzerinden ikinci bir zamanlanmış görev (`companionTaskId`) eklendi ve `/etc/cron.d/yunpanel-${companionTaskId}` dosyasının oluştuğu SSH ile teyit edildi.
  3. İlk görev arayüzden onaylanarak silindi.
  4. Fiziksel kontrol ile yalnız ilk görevin dosyasının kaldırıldığı (`NOT_FOUND`), buna karşın ikinci görevin cron dosyasının (`EXISTS`) ve API kayıtlarındaki durumunun (`hostFileExists: true`) eksiksiz korunduğu kanıtlandı.
  5. İkinci görev de API üzerinden silinerek sunucuda 0 artık bırakıldı.
