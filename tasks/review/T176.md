# T176 — Manuel test: TLS-02 — Wildcard/DNS-01, SAN ve www/mail/webmail kapsamı
Yapan: AGENT_3 · Teslim: 2026-10-28 11:34

## Yapılanlar
- TLS-02 özelliği için `e2e/ozellik/tls-02.spec.js` senaryosu gerçek panele ve canlı sunucu ortamına karşı sıfır mock/stub ile yazıldı.
- `webrich.news` web sitesi SSL sekmesinde (`/websites/:id/ssl`) sertifika kapsamı (SAN) arayüzde ve fiziksel olarak doğrulandı:
  - SSH üzerinden OpenSSL x509 incelemesinde SAN listesinde `DNS:webrich.news, DNS:www.webrich.news` bulunduğu teyit edildi.
  - Port 443 Nginx canlı TLS el sıkışmasında sunulan sertifikanın SAN listesi teyit edildi.
  - Mail servisi kimliği (`/api/panel/mail-service-identity` -> `mail.webrich.news`, `ready: true`) ve Dovecot IMAPS port 993 el sıkışmasında `CN = mail.webrich.news` fiziksel olarak doğrulandı.
- Yeni geçici web sitesi oluşturularak (`ttls02-a3-...webrich.news`) sertifikası olmayan bir sitede SSL başvuru formu ve alt alan adı seçenekleri arayüzde test edildi:
  - Ana alan adı checkbox (zorunlu, disabled ve checked)
  - `www`, `webmail`, `mail`, `assignToMail` ve `includeWildcard` (Joker) checkbox seçenekleri
  - "Joker (Wildcard)" seçildiğinde "⚠️ Joker sertifikalar Cloudflare DNS-01 doğrulaması gerektirir." uyarı metninin çıkması ve kaldırılınca gizlenmesi
  - Formdaki değişiklikleri sıfırlama (Reset) etkileşimi
- Hatalı girdi ve güvenlik sınırları API seviyesinde test edildi:
  - Yetkisiz / yabancı domain SAN olarak eklenmek istendiğinde 409 `certificate_domain_mismatch` reddi
  - DNS-01 challenge olmadan wildcard (`*.domain`) istendiğinde 409 `wildcard_not_supported` reddi
  - 21 adetten fazla SAN listesi verildiğinde 400 `invalid_certificate_domains` reddi
  - Boş veya geçersiz domain dizisinde 400 `invalid_certificate_domain` reddi
  - DNS-01 challenge nesnesinde geçersiz DNS Zone ID verildiğinde 404 `dns_zone_not_found` reddi
- Plesk SSL It! / Let's Encrypt uzantısı eşdeğerlik eksiklikleri tespit edilip `test.fail` ile işaretlendi:
  - Arayüzde Wildcard talep edilirken DNS-01 sağlayıcı (Cloudflare) token veya DNS zone yapılandırma formu bulunmuyor (form doğrudan gönderildiğinde 409 hatası oluşuyor).
  - Yerel PowerDNS üzerinden otomatik DNS-01 challenge veya harici DNS için manuel TXT prompt ekranı eksik.
  - Aktif sertifikalı sitede sertifika kapsamını genişletme (Reissue Certificate with SANs) arayüzü eksik (yalnızca ACME yenileme paneli gösteriliyor).
- `docs/manuel-test/TLS-02.md` raporu oluşturuldu (30 satır, <= 40 satır kuralına uygun).
- `afterAll` hook'unda oluşturulan geçici test siteleri arayüzden kalıcı olarak silindi ve 0 artık bırakıldı.
- Test 2 ardışık kez koşturularak %100 kararlılık kanıtlandı (1. koşu 58.3s, 2. koşu 57.3s).
