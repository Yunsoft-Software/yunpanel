## Helper — `@yunpanel/shared/json-file-store` (yalnız exports alt yolu; tarayıcı index'ine girmez)
- `writeTextAtomic(path, text, { mode=0o600, directoryMode, enforceDirectoryMode=false })`: üst dizin `mkdir` (verilirse `directoryMode`; `enforceDirectoryMode` eski `chmod(directory)` satırının karşılığı) → mevcut ana dosya JSON olarak okunabiliyorsa `<path>.bak`'a dayanıklı kopya → aynı dizinde `<path>.<pid>.<uuid>.tmp` `wx` → yaz → `fsync` → `chmod mode` → `rename` → dizin `fsync`. Hatada geçici dosya silinir. Bozuk ana dosya iyi `.bak`'ın yerine geçmez.
- `writeJsonAtomic(path, value, { space=2, trailingNewline=false, ...})`: çağrı anında serileştirir.
- `readJsonWithFallback(path, { onRecovered })`: ana dosya yoksa `ENOENT` hatasını aynen fırlatır (çağıranların "yoksa boş" dalı değişmedi). Boş/bozuk ise `.bak` okunur, `onRecovered({ filePath, backupPath, reason })` çağrılır; varsayılan tek satır `console.warn` yalnız dosya adı ve neden yazar. İkisi de bozuksa ana dosyanın `SyntaxError`'ı fırlar → çağıranın eski hata kodu/fail-closed davranışı aynı. Şema geçersizliği (geçerli JSON) `.bak`'a düşmez.
