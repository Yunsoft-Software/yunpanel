- Mutlu yol:
  - SSH ile `ip -br a` komutu çalıştırılarak host seviyesinde fiziksel ağ arayüzleri ve atanan IP adresleri tespit edildi (`ens18`, `157.180.11.28`, `fe80::...`).

  - API'den dönen `inventory.network` yapısında IPv4 (`157.180.11.28`) ve IPv6 (`fe80:...`) adreslerinin arayüz bazlı (`ens18`) olarak tam eşleştiği kanıtlandı.

  - Var olmayan sunucu ID (`/api/panel/servers/00000000-0000-0000-0000-000000000000`) çağrısında 404 `local_server_required` hatası doğrulandı.

  - Oturum çerezi bulunmayan isteklerde 401 Unauthorized koruması doğrulandı.

  - Plesk'teki Tools & Settings -> "IP Addresses" havuz yönetimi, arayüz bazlı IP listeleme/ekleme, IP türünü "Shared" veya "Dedicated" olarak değiştirme, site/müşteri bazlı Dedicated IP tahsisi ve "IP Re-mapping" aracının YunPanel UI ve API'sinde henüz bulunmadığı tespit edildi ve `test.fail` ile işaretlendi.
