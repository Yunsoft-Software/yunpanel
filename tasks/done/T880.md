## 3. Yapılan Düzeltmeler (b)

### 3.1. `e2e/live-audit/07-subsystem-mutation.spec.js`
1. **Mail Alan Adı Formu Seçicileri:**
   - Mail domain oluşturma modalındaki combobox etiketinin `Alan adı` olduğu teyit edildi (`getByRole('combobox', { name: /Alan adı|Web Domain/i })`).
   - Dovecot/Postfix konfigürasyonunun arka planda 30-45 saniye sürebilmesi sebebiyle dialog kapanma timeout'u 90 saniyeye ve test timeout'u 180 saniyeye çıkarıldı.
2. **IMAP TLS Sertifikası:**
   - Dovecot servisinin geçerli TLS CN'inin `mail.webrich.news` olduğu tespit edilerek TLS SNI `servername: 'mail.webrich.news'` olarak ayarlandı.
3. **Webmail Doğrulaması:**
   - Önizleme / hazır bağlantı durumu için `getByRole('heading', { name: /Webmail/i })` ile görünüm doğrulandı.
4. **Docker Compose Formu ve API Uyarlaması:**
   - Buton metni regex'i `/Compose.*(Stack|projesi).*(Ekle|ekle)|Compose \/ Stack Ekle/i` olarak esnetildi.
   - `GET /api/panel/docker/projects` yanıtının doğrudan bir dizi döndüğü tespit edilerek `Array.isArray(allProjects.data)` kontrolü eklendi.

### 3.2. `e2e/live-audit/09-role-mutation.spec.js`
1. **phpMyAdmin Doğrulaması:**
   - Henüz 13 çalışmadan önce veritabanında `yp_native_proof` tablosu bulunmadığından, phpMyAdmin arayüzünde veritabanı yapısının ve breadcrumb linkinin açıldığı `new RegExp('yp_native_proof|' + m.fixture.databaseName, 'i')` regex'i ile doğrulandı.
2. **Foreign ID Fallback:**
   - `m.fixture.extraStatic` tanımlı olmadığında `m.existingPhpWebsiteId` fallback'i kullanılarak yetkisiz erişim testi korundu.
