## Yapılanlar
- SEC-01 özelliği için `e2e/ozellik/sec-01.spec.js` senaryosu gerçek panele, gerçek API'ye ve canlı test sunucusuna (`yunpanel-test`) karşı sıfır mock/stub ile yazıldı.
- Mutlu yol:
  - Güvenlik duvarı genel durumu (`/api/panel/firewall/status`) başarıyla sorgulandı (durum, kernelRules, bootPersistence, crowdsec).
  - Port listesi (`/api/panel/firewall/ports`) sorgulandı; SSH (22 TCP) kuralının sistemde dinlediği doğrulandı.
  - Özel zararsız test portu (49200-49600 aralığında) eklendi (`POST /api/panel/firewall/ports`), kural listesinde varlığı doğrulandı.
  - Güvenli geri dönüş ve etki analizi önizlemesi (`POST /api/panel/firewall/preview`) test edildi; `valid: true`, `impact` ve `candidateSha256` nesneleri doğrulandı.
  - Eklenen test port kuralı silindi (`DELETE /api/panel/firewall/ports/:port`).
  - Fiziksel kanıt: SSH ile test sunucusunda nftables kural zincirleri (`sudo nft list ruleset | grep -c "chain"`) ve UFW durumu (`sudo ufw status`) fiziksel olarak kanıtlandı.
- Hatalı girdi ve güvenlik sınırları:
  - Geçersiz port numarası (99999) 400 `invalid_port` ile reddedildi.
  - Geçersiz kaynak IP/CIDR (`999.999.999.999/99`) 400 `invalid_cidr` ile reddedildi.
  - Local-mail servis profili kapalıyken mail portu (25) açma denemesi 400 `service_profile_inactive` ile engellendi.
  - SSH portunu silme teşebbüsü 400 `lockout_risk_detected` (idari kilitlenme riski koruması) ile engellendi.
  - Port tarama motorunda yetkisiz hedef (.44 Plesk hedefi) 400/403 `unauthorized_test_target` ile reddedildi.
- UI ve Parity tespiti:
  - `FirewallPage.jsx` bileşeni başlık, genel durum kartları ve servis profilleri kartlarıyla DOM'a render edilmektedir.
  - Ancak frontend istemcisi `firewall-client.js`, API kök yolunda `/api/panel/` önekini kullanmayıp doğrudan `/api/firewall/*` çağırdığı için web reverse proxy (server.js) bu istekleri 404 olarak karşılamakta ve arayüzde port listesi boş kalmaktadır. Bu durum `test.fail` ile belgelendi.
- Sıfır artık ilkesi: `afterAll` hook'unda test port kuralı host üzerinden temizlendi; sistem başlangıç durumunda bırakıldı.
- `docs/manuel-test/SEC-01.md` raporu oluşturuldu (25 satır, <= 40 satır kuralına uygun).
