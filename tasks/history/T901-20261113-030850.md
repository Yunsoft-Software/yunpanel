2. **Immutable build manifest üretimi, dirty çalışma ağacı koruması ve exact `--verify-web-dist` doğrulaması (`scripts/emit-build-info.mjs`, `apps/web/vite.config.js`, `scripts/build-deb.sh`):**
   - **Bulgu 1 çözümü (Dirty Git Working Tree):** `scripts/emit-build-info.mjs` içinde `git rev-parse --show-toplevel`, `git rev-parse HEAD` ve `git status --porcelain --untracked-files=normal` birlikte kontrol ediliyor. Yerel WIP derlemesinde (`vite build` / varsayılan mod) kaydedilmemiş değişiklik varsa derleme kırılmaz ancak manifest açıkça `dirty: true, buildVerified: false` olarak yazılır; hem `deployment-diagnostics-client.js` hem `core-app.js` bunu doğrulanmamış (`UNKNOWN` / `Doğrulanmadı`, `sourceMatchesDeployed: false`) kabul eder. Release/paketleme modları (`--require-clean` ve `--verify-web-dist`) ise dirty çalışma ağacını veya `dirty: true` / `buildVerified !== true` web manifestini **fail-closed (`exit 1`)** reddeder.
   - **Bulgu 2 çözümü (`--verify-web-dist` exact kimlik ve override reddi):** `--verify-web-dist <path>` verildiğinde doğrulanmış (`buildVerified === true && dirty === false`) web manifestinin yalnız `version` ve `commit` değil, immutable `buildId`, `assetId` ve `buildTime` alanları da birebir korunur. Explicit env override (`YUNPANEL_VERSION`, `YUNPANEL_COMMIT_HASH`/`YUNPANEL_BUILD_COMMIT`/`GIT_COMMIT`, `YUNPANEL_BUILD_ID`, `YUNPANEL_ASSET_ID`, `YUNPANEL_BUILD_TIME`/`BUILD_TIMESTAMP`) verilmemişse paket manifesti web manifestinin exact `{ version, schemaVersion, buildId, assetId, commit, buildTime, dirty: false, buildVerified: true }` kimliğini aynen devralır; herhangi bir env override web manifestiyle çelişirse **fail-closed (`exit 1`)** reddeder.
   - `scripts/build-deb.sh` artık `--require-clean` ve `--verify-web-dist "$repository_root/apps/web/dist/build-info.json"` bayraklarıyla `/usr/lib/yunpanel/build-info.json` (`0644`) dosyasını üretir.
