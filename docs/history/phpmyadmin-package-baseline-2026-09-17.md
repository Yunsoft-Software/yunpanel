# phpMyAdmin managed-package baseline — 2026-09-17

Bu dilim shared phpMyAdmin ürün akışının managed package, isolated runtime ve backup-backed activation temelini tamamlar; protected panel signon handoff veya Website-scope browser oturumu henüz hazır değildir.

- Managed-service allowlist'i Ubuntu `phpmyadmin`, `php-fpm` ve `php-mysql` paketlerini exact sırayla kurar.
- Health inspection yalnız `/usr/share/phpmyadmin/index.php`, `/etc/phpmyadmin/config.inc.php` ve sabit PHP syntax kontrolünü çalıştırır; komut çıktısını job/public state'e taşımaz.
- phpMyAdmin daemon gibi modellenmez: `active=false`, `units=[]`, `health.status=installed` döner ve systemd control operation'ı queue edilmeden reddedilir.
- Durable result sanitization, mutation receipt ve restart recovery unitless uygulama davranışını sabit servis politikasından türetir; Roundcube adına bağlı özel recovery kuralı kullanılmaz.
- Deterministic PHP 8.3 FPM template'i `yunpanel-phpmyadmin` identity'sini, ayrı socket'i, private temp/session dizinlerini, strict/secure/HttpOnly/SameSite session ayarlarını ve bounded upload limitini sabitler.
- Nginx template'i public TCP listener üretmez; yalnız `/run/yunpanel/phpmyadmin-http.sock` Unix socket'ini ve packaged gateway kimliği için `root:yunpanel 0660` metadata kontratını yayınlar. `setup`, `test`, `libraries`, `templates` ve hidden path erişimleri reddedilir.
- Host staging manager yalnız exact preview shape/digest/byte sözleşmesine uyan FPM ve Nginx içeriklerini digest-scoped `0700` dizinlere `0640` olarak atomik yazar; content/mode/symlink veya runtime/socket identity metadata drift'ini fail-closed raporlar.
- Debian post-install `yunpanel-phpmyadmin` locked system user/group'unu, `www-data` package-config üyeliğini ve identity-owned `0700` home/tmp/session dizinlerini idempotent hazırlar. Gateway socket grubu gerçek `yunpanel-web.service` kimliği olan `yunpanel` ile eşleştirilmiştir.
- Transaction-scoped backup manager önceki FPM/Nginx dosyalarının presence, checksum, byte, uid/gid ve mode kanıtını `0700`/`0600` root-private state'te saklar; exact restore pre-existing dosyayı atomik geri koyar, operation öncesi absent target'ı kaldırır ve symlink/tamper/expanded manifest state'ini reddeder.
- Host activator yalnız exact FPM/Nginx preview shape'i ve staged digest/byte/mode kanıtı doğrulandıktan sonra mutation'a geçer; runtime identity, `www-data` package-config üyeliği, private home/tmp/session dizinleri ve config parent'ları mutation öncesinde fail-closed doğrulanır.
- Activation FPM ve Nginx config'lerini root-owned `0640` olarak atomik yerleştirir, `php-fpm8.3 -t` ve `nginx -t` sonrasında ilgili servisleri reload eder. FPM socket'inin `www-data:www-data 0660`, internal HTTP socket'inin `root:yunpanel 0660` olduğunu doğrular; gateway metadata drift'i yalnız beklenen Unix socket üzerinde düzeltilip tekrar okunarak kanıtlanır.
- Endpoint health public TCP üzerinden değil `curl --unix-socket /run/yunpanel/phpmyadmin-http.sock http://localhost/` ile doğrulanır. Activation'ın herhangi bir mutation/configtest/reload/socket/health hatasında transaction backup restore edilir; restored FPM/Nginx config'i tekrar validate/reload edilir ve operation öncesi absent socket'lerin retire olduğu doğrulanmadan rollback başarılı sayılmaz.
- `/run/yunpanel` ephemeral parent'ı kurulum anında `root:yunpanel 2770` hazırlanır ve paket artık `/usr/lib/tmpfiles.d/yunpanel.conf` ile aynı kontratı reboot sonrası yeniden üretir; setgid parent gateway socket'in `yunpanel` grubunu kalıcı runtime sınırında tutar.
- Protected `Open phpMyAdmin` signon/short-lived Website handoff, import/export scope binding ve cross-Website browser isolation halen plan/TODO'da açıktır. Gerçek Ubuntu package/debconf/FPM/Nginx/reboot kabulü `todo.md` içindedir ve canlı kabul geçmeden ürün seviyesi `DONE` sayılmaz.

Kaynak testleri protocol katalog/validation, host install/inspect, API result policy, HTTP queue boundary, receipt-backed restart recovery, FPM/Nginx template determinism/fail-closed path kuralları ve phpMyAdmin activation'da stage drift, runtime group guard, socket/Unix-HTTP health ile exact rollback davranışını kapsar.
