# Passenger Git yayınlama ve geri alma

İlk Website kurulumu ve ortam yeniden başlatma native çalışır. 12 Ekim kaynak dilimi normal API/ekranın adapter seçimini açık Passenger deploy/rollback operasyonlarına bağladı; eski systemd sözleşmesi korunur. Dedicated-site release manager aday hazırlama ve yayınlamayı ayırır; retained geri alma yeniden derleme yapmaz. `.28` üzerindeki `0.3.0-2026101133` paketinde normal ikinci Git yayını ve retained geri alma; gerçek HTTPS içerik farkı, current link, site UID/process cwd ve özel ortam hash eşleşmesiyle geçti. Preparing halinde kalan gerçek iş, tüketiciler durdurulduktan sonra packaged CLI compensation ile önceki çalışan sürüme döndü; failed geçmiş korundu ve recovery kuyruğu temizlendi. `0.3.0-2026101134` paketinde ikinci Domain DNS/SSL/stage/activate ve iki gerçek HTTPS Domain'den günlük Git deploy/rollback geçti. Node dosyası ve özel ortam değeri iki ayrı değişiklikten sonra aynı explicit Restic snapshot'ından iki kez geri yüklendi; fiziksel dosya/UID, süreç cwd/UID/özel değer hash'i ve sonradan eklenen anahtarın gerçek süreçten yokluğu doğrulandı. Test yedekleri ve site kaynaklarının normal temizliği açık kalır.

Yeni açık Passenger deploy/rollback operasyonları backend adapter seçimiyle çalışacak; eski systemd işi Passenger'a dönüşmez. Backend uygulama adapterından operasyonu seçer. Tek Website/Application/sunucu/Unix bağı, kuyruktaki yapılandırma ve önceki release, kaydedilmiş ortam revision'ı, aktif runtime binding ve tam Domain routing kanıtı yürütme başında ve native değişiklikler öncesinde doğrulanır. Aynı site kilidi ve tenant reauthorization korunur.

Yayın, dedicated Unix kullanıcıyla hazırlanır. Yeni fiziksel release/commit, ortam ve Nginx trafiği doğrulanmadan başarılı olmaz. Application release, Domain checksum ve runtime binding birlikte aynı gerçek hedefe uzlaştırılır. Hata veya kayıp cevapta kalıcı iş/receipt aynı operation'a bağlanır; eski route/release/ortam geri alınır. Aktif süreç salt geçen süreyle sonlandırılmaz. Native phase, config rollback ve recovery kayıtları rutin tedbir yedeği değildir.

Geri alma yalnız aynı uygulamanın retained ve fiziksel sahipliği doğrulanan release'ine yapılır. Eski veya yabancı Unix/root yoluna geçmez. Geri alınan runtime, gerçek process cwd/UID ve HTTP sonucu metadata/binding ile eşleşir. Yeni veri/env drift'i veya belirsiz receipt varsa mutasyon durur.

Kabul kapıları: kaynak başarı/hata/idempotency/tenant/revision/rollback ve crash recovery senaryoları; bağımsız inceleme; `.28` üzerinde ikinci Git release, fiziksel eski/yeni içerik ve process/HTTP/env karşılaştırması, gerçek rollback, iki backup restore ve ardından yalnız test kaynaklarının temizliği. Bu belge uygulamanın tamamlandığına dair kanıt değildir.

12 Ekim odak kaynak senaryoları: ikinci yayın/retained geri alma, derleme sonrası oturum iptali, iki domainin kısmi reload geri alması, markStaged/markApplied ve binding/env metadata kesintisi, kayıp completion, compensating kesintisinin aynı protected state ile devamı, foreign native env drift ve silinen managed anahtarların süreçte yokluğu. Kalıcı phase encrypted original/desired env ile exact job/Website/payload identity'ye bağlıdır; compare-and-swap, transition graph ve dosya/dizin fsync uygulanır. Packaged root CLI `recover-passenger-release` veya `compensate-passenger-release` için exact server/job ve `--confirm` ister; tüketiciler durmadan açılmaz. Eski failed job kabul edilen fiziksel state uzlaştırıldığında da failed geçmişini korur. Kaynak fixture/proc kanıtı native kabul değildir.

İkinci Domain'in ilk hazırlaması için server-owned Application/Website/release/revision bağı eklendi. Varsayılan resolver kayıtlı Domain kanıtını zorunlu tutar; yalnız ilk, henüz hazırlanıp uygulanmamış draft/error için stage kuyruğu bu bağı üretir. Aynı Application kilidi altında bu Website'ın önceki Passenger stage işi bitmeden yenisi alınmaz; mevcut 32 Domain sınırı enqueue öncesinde uygulanır. Başarılı stage yalnız kendi Domain evidence'ini binding CAS ile ekler. Stoppedconsumer domain recovery Website/runtime binding kayıtlarını gerçek guarded store'lardan yükler. Bu yeni dilimin kaynak testleri geçti; yeni paket ve fiziksel ikinci Domain kabulü tamamlanmadan kapanmaz.
